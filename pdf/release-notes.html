Section 01
The interface is new, not moved around

The desktop application you have been running was a Windows program with its own interface. 4.0 replaces it with the interface QSAR Flex uses on the web, wrapped in a native application for Windows and macOS. Nothing you have saved is affected.

01 · The navbar
Everything is in one bar

A single bar across the top carries Library and DataKurator on the left, a Search box in the middle, and your license status, documentation and theme on the right. There are no menus above it and no toolbars below it.

02 · Two screens
Library, and DataKurator

The Library holds the compounds and reactions you are working on and is where you evaluate. DataKurator is where you clean a set before it gets there. You move between them with the two tabs, and work is kept on both.

03 · The command bar
Search for the thing you want

Press ⌘K or Ctrl K and type. It searches every action in the product and runs it from wherever you are, naming where each control lives. It is the fastest way to find a feature you cannot see.

The Library, with the whole interface around it

Left to right along the bar: the Library and DataKurator tabs, the Search box that the command bar opens behind, then your license status, the documentation button and the light/dark toggle. Below it, + Compounds, + Reaction and Evaluate, and one card per compound with its structure beside its outcomes. Clicking an outcome opens the report.

Section 02
What you could not do before
Platform
QSAR Flex runs on macOS
A native Apple Silicon build, signed by Apple and notarized, installs by dragging it to Applications and needs no administrator rights. It is the same application as the Windows one: the same interface, the same modules, the same reports. Until now the desktop was Windows only.
Library
Drop a file anywhere, or paste structures
No dialog to open first. Drop files onto the page or paste SMILES directly, and the file extension decides which importer runs, so compounds and reactions in the same drop are separated for you. Structures are drawn in the current theme, so a depiction is legible on paper and on a dark screen. Clicking a reaction opens a dialog sized for the scheme rather than for one molecule.
DataKurator
Real undo, and bulk correction you can inspect
Curation keeps a fifty-step history and every step is named, so a tooltip tells you what will come back before you press it. One Step Cure is a single dialog with four counted decisions, plus optional passes for chiral tags, charge neutralization and PubChem verification. A bulk run finishes in a summary you can filter down to the rows that still need attention instead of silently redrawing the table.
Everywhere
Long runs report what they are doing, and can be canceled
Evaluation, curation and file loading run behind a progress overlay that names the phase it is in rather than showing a percentage. All three can be canceled, and canceling says what was left alone. If a run returns fewer results than it was given, a banner says so and names the counts, so a short run is never quietly presented as a complete one.
Licensing
An Account page, and license activity you can read back
Account gathers Profile, Security, License and Team in one place. The navbar chip shows tests remaining, Unlimited, or that a license has expired, and opens the same page in a click. Each license has an activity page listing every evaluation with its user, modules, item count and billing state, which is what an invoice reconciles against. Enterprise administrators assign and remove seats and create users themselves, without involving MultiCASE.
Support
A support portal, which did not exist before
Until now support meant an email thread. support.multicase.com is new in this release. It is a site of its own: open it in a browser and sign in with the same MultiCASE account you use for QSAR Flex, with no separate registration. QSAR Flex itself links out to the documentation, not to the portal. Raise a ticket for anything: access, licensing, bundles, seats, bugs or questions. Attach whatever shows the problem, follow the ticket to resolution, and see its status rather than guessing at it. Replies come back in the thread. Use the portal rather than emailing support or info at multicase.com.

Section 03Unchanged
What has not changed, and one thing you may not know

The interface is new. The chemistry underneath it is not. If you have validated a QSAR Flex result, 4.0 does not move it.

The modelsThe same statistical models, expert alerts, read-across and rule-based methods, with the same applicability-domain and uncertainty handling.
The endpointsThe same catalog: sixteen modules in four bundles, Nitrosamine, Ecotoxicity, Physicochemical and ADME.
The resultsPredictions, reports and their supporting evidence come from the same engine. Every record count and every number a model returns is the same.
The license typesIndividual or Enterprise coverage, and still Subscription, On-Demand Subscription and Pay-Per-Test, with the same module and bundle entitlements.
Sign-in and dataStill your MultiCASE account. There is no data migration and no license re-issue, and the desktop application still evaluates on your own machine.
You also have a web application

The interface in 4.0 is the one QSAR Flex has been running in the browser, and your license covers it. Sign in at qsarflex.multicase.com with the same account: nothing to install, nothing to download, and it stays current on its own. It suits people who move between machines, or a colleague who needs occasional access without a deployment.

Two differences worth knowing. The web application sends your structures to MultiCASE to be evaluated, where the desktop evaluates them on your own machine and sends none. And Surrogate Search and Cross Similarity are desktop-only, because they read across the whole reference database rather than fetching one record. If structures may not leave your network, stay on the desktop.

Getting started on 4.0
The installation guides, a walkthrough of the new interface and the full model catalog are on resources.multicase.com. Anything else, open a ticket with the account you already use.
