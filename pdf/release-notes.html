Section 01Read first
Three things that behave differently

Nothing in 4.0 needs a migration and no saved work is affected. Three habits from 3.x will not carry over, and they are the changes most likely to generate a support ticket in the first week.

01 · Keyboard
⌘K no longer opens Evaluate

In 3.x, ⌘K / Ctrl K opened the Evaluate dialog. It now opens the command bar. To evaluate from the keyboard press ⌘K, type evaluate and press Enter; the command runs from any page. The green Evaluate button in the Library toolbar is unchanged.

02 · DataKurator
Two buttons are gone

Proceed to Export no longer exists; export is a Download menu on the Curate screen. PubChem Batch Correct is no longer a button either; it is a checkbox inside the One Step Cure dialog. Curation is now Upload then Curate, not Upload, Curate, Export.

03 · Library
An empty Library hides its toolbar

+ Compounds, + Reaction, Evaluate and Clear all are hidden while the Library is empty. In their place is a single card offering the two actions that make sense at that point. The toolbar returns as soon as something is loaded.

Nothing else about upgrading needs planning. There is no data migration, no licence re-issue and no change to how you sign in. The desktop application updates itself, per user, without administrator rights.

Section 02
What changed
Interface
One navbar, and a command bar in it
The old top navigation is gone. A single 48-pixel bar carries the Library and DataKurator tabs, a Search control on ⌘K, your licence status, a Documentation button and the theme control. The command bar searches every action in the product and runs it from any page: ask for a DataKurator command while standing in the Library and it takes you there and fires on arrival. Actions that cannot run are still listed, greyed, with the reason.
Interface
Light and dark themes
Light, Dark and System. Structures are drawn by the engine in the current text colour, so a depiction is legible on paper and on a dark screen instead of being a white tile.
Library
Drop a file anywhere, or paste structures
No dialog needed. Drop files onto the page or paste SMILES straight in. The extension decides which importer runs, so compounds and reactions in the same drop are sorted for you. Compound and reaction cards were redrawn for contrast in both themes, and clicking a reaction scheme opens a dialog sized for the scheme rather than for a single molecule.
DataKurator
Upload then Curate, with export on the same screen
Loading a file analyses it, so the old third step is gone. The Download menu sits in the Curate action bar. Undo and redo keep a fifty-step history and every step is named, so a tooltip tells you what will come back: Undo One Step Cure, Undo Split into 3 components.
DataKurator
One Step Cure is a single dialog
Four decisions, each showing how many rows it applies to, plus optional passes for chiral tags, charge neutralisation and PubChem verification. A bulk run now finishes in a summary you can filter down to the rows that still need attention, rather than silently redrawing the table. PubChem remains opt-in: any lookup raises a dialog naming exactly what would be sent.
Licensing
An Account page, and licence activity
Profile is now a full Account page with Profile, Security, License and Team tabs. The navbar chip shows tests remaining, Unlimited, or that a licence has expired, and takes you to the same place in one click. Each licence has its own activity page listing every evaluation with its user, modules, item count and billing state. Enterprise users who are not company administrators see an explicit View only badge.
Support
A portal instead of an inbox
Support has moved to support.multicase.com, signed in with the same MultiCASE account you use for QSAR Flex. Open a ticket for anything: access, licensing, bundles, seats, bugs or questions. Replies come back in the ticket thread, and the status is visible rather than guessed at. Use the portal rather than emailing support or info at multicase.com.
Throughout
Runs you can watch, and results you can trust
Long operations report named phases instead of a fake percentage, and can be cancelled cleanly. If a run returns fewer results than it was given, a banner says so and names the time, the counts and the modules. Every blank screen says what to do next and offers the action that does it.

Section 03Unchanged
What has not changed

If you have validated a QSAR Flex result, 4.0 does not move it. The release changed the interface around the engine, not the chemistry.

The modelsThe same statistical models, expert alerts, read-across and rule-based methods, with the same applicability-domain and uncertainty handling.
The endpointsThe module catalog and its bundles are unchanged: sixteen modules in four bundles, Nitrosamine, Ecotoxicity, Physicochemical and ADME.
The resultsPredictions, reports and their supporting evidence come from the same engine. Every record count and every number a model returns is the same.
The licence typesCoverage is still Individual or Enterprise. The types are still Subscription, On-Demand Subscription and Pay-Per-Test, with the same module and bundle entitlements and the same enterprise seat management.
Sign-inStill your MultiCASE account, and still the same account across QSAR Flex and the support portal.
Where evaluation runsThe desktop application still evaluates on the workstation. The web application still sends structures to the QSAR Flex service. Neither has changed in this release.

One correction to earlier documentation. In the web application, DataKurator sends your structures to the QSAR Flex service for its curation checks. Earlier documentation implied the analysis ran in the browser. The desktop application curates in the application process, against the reference data on the machine.

Questions about the upgrade?
Open a ticket at support.multicase.com with the same account you use for QSAR Flex. The full user guides, the model catalog and the IT deployment guide are on resources.multicase.com.
