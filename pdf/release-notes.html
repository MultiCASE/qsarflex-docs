QSAR Flex 4.0

Release Notes  ·  October 2026

QSAR Flex 4.0 has a new interface and runs on Windows, macOS and the web. The models and the results are the same as in 3.x. A result you validated on 3.x is the same result on 4.0.

What changed

  • New interface. The desktop application now uses the same interface as the web application. Nothing moves between screens.
  • macOS. QSAR Flex runs on macOS (Apple Silicon) for the first time. It is the same application as the Windows one.
  • One workspace. You load, check and evaluate compounds in one table. Every compound is checked as it loads, and the finding is shown on its row.
  • Results on the row. After an evaluation, each row lists its modules. Click a module to open its report.
  • Reports. Reports open from the Results column or from the row's panel, and you save them as PDF from the report itself.
  • ChemiGraphy built in. Draw a compound, or fix one the check flagged, without leaving QSAR Flex. ChemiGraphy also draws every structure on screen and in every report.
  • Curation. One Step Cure fixes mixtures, duplicates and atom-type errors in one step and shows how many rows each choice affects before you confirm. Every change can be undone.
  • Search. Press ⌘K (Mac) or Ctrl K (Windows) to find and run any action by name.
  • Sign-in. The desktop applications keep you signed in between launches. The browser sign-in appears only the first time, after you sign out, or when the session has ended.
  • Account page. Profile, Security, License and Team are in one place. Each license lists every evaluation run against it.
  • Progress. Long runs show what they are doing and can be cancelled. If a run returns fewer results than it was given, it says so.
  • Support portal. Raise and follow tickets at support.multicase.com with the account you already use.

What did not change

  • The models, the endpoints and the results. Sixteen modules in four bundles, as before.
  • Your account and your license. There is no data migration and no license re-issue.
  • The desktop application still evaluates on your own machine. The web application sends structures to MultiCASE for the length of an evaluation and does not keep them.

Getting 4.0

  • Download the Windows or macOS application from downloads.multicase.com, or sign in at qsarflex.multicase.com. On first run the desktop downloads about 4 GB of reference data.
  • Guides and the model catalog are at resources.multicase.com. For anything else, open a ticket at support.multicase.com.
