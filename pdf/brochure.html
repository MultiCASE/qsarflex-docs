From a list of structures to a defensible answer
Section1

QSAR Flex is a workbench, not a single calculator. Assemble a library of molecules, curate them, choose the models that bear on your question, and review the predictions. Whether you are screening one impurity or a few thousand, the results arrive in a form you can read, check and defend.

4‑Aminobiphenyl. An alert names the atoms it fired on, and the report marks exactly those.
1
Load
SMILES, InChI, SDF, MOL, delimited text or MDL RXN. Drop files on the page or paste structures straight in.
2
Curate
Every compound is checked as it arrives; mixtures, duplicates and bad atom types are flagged before they reach a model.
3
Select
Pick modules from the bundles your licence covers. Everything else stays visible but disabled.
4
Evaluate
Each compound and reaction is run against each selected module, with progress you can cancel.
5
Report
Click a module's name in the Results column to open a self-contained HTML report carrying the evidence behind it.
Nine ways to answer a question

A module is not always a regression. The engine carries linear and logistic regression, naive Bayes, random forests, Bayesian networks, SMARTS expert alerts, fragment descriptors, fingerprint read-across and alert-local read-across. The Basis column of the model catalogue (section 4) says which kind each module uses. The method is chosen when the model is built, so a nitrosamine potency call and a boiling point arrive in the same results table.

A prediction that says when to distrust it

Applicability domain is checked explicitly, by similarity to the nearest training-set neighbours or by looking for fragments of your query that the training set never covered. An outcome outside the domain is labelled out of domain in the report rather than quietly returned as a number. When the domain is assessed by fragments, the unmodelled part of the molecule is identified, so you can see which part of the structure the model has never seen.

One file, nothing to unpack. A report is a single self-contained HTML file with its structures drawn inline, and the software, version and run date recorded. Save as PDF from the report itself and it becomes a PDF fit for a dossier.

What is new in 4.0
Section2

4.0 rebuilds the entire user interface. The models, the endpoints and the numbers they return are unchanged. This release is about how quickly you can get a library in, get it clean, and get the answer out.

Propranolol, as ChemiGraphy draws it. In 4.0 every structure you see, on screen and in every report, is drawn this way.

ChemiGraphy, MultiCASE's structure editor, built in. Draw a compound instead of typing it, or open a flagged compound and correct it on the canvas. The engine that checks and evaluates your compounds reads what you draw, and ChemiGraphy draws every structure you see, on screen and in every report.

One interface, three places to run it. The web application, the Windows desktop and the macOS desktop render the same interface. A single navigation bar carries Add, Curate and Evaluate, the command bar, your licence status, and a light or dark theme that follows your system.

One workspace, checked as it loads. Drag a file anywhere onto the page or paste SMILES from the clipboard. Every compound is checked as it arrives and wears its verdict on the row; a panel beside the table holds the structure, the finding and the fix. Every change can be undone and redone by name, and One Step Cure shows how many rows each choice affects before you commit.

A command bar for every action. ⌘K, or Ctrl K, opens a search over every action in the product. Commands work from any page: run Evaluate from your Account page and you are taken to the workspace and it fires on arrival. Actions that are not available are still listed, greyed, with the reason why.

Your licence, in plain sight. A status chip in the navigation bar shows tests remaining, or Unlimited, or that a licence has expired. The Account page gathers Profile, Security, Licence and Team in one place, so a question about entitlement no longer needs an email.

A support portal, not an inbox. Support moves to support.multicase.com, a site of its own, opened in a browser and signed in with the MultiCASE account you use for QSAR Flex. Raise a ticket against a specific product, attach the files that show the problem, and follow the thread, with the status visible instead of guessed at.

Also in 4.0

Structures. Depictions are drawn in the current theme, so a structure is legible on paper and on a dark screen.

Empty states. Every blank screen says what to do next, and offers the action that does it.

Partial runs. If a run returns fewer results than it was given, a banner says so. Nothing is quietly presented as complete.

Cancelling. Long operations report named phases and stop cleanly, telling you exactly what did and did not change.

Unchanged in 4.0. Every model, every endpoint, every record count and every number a model returns. Licence types are unchanged too: subscription and pay-per-test, individual or enterprise. A prediction you validated in 3.x returns the same answer in 4.0.

Curation: get the workspace right first
Section3

A model can only be as good as the structure you hand it. QSAR Flex checks a set the moment it loads, tells you exactly what is wrong with each row, and gives you bulk and single-row tools to fix it, with undo behind every change.

Ibuprofen sodium, as loaded. The check flags it as a mixture; One Step Cure can keep the largest part by atom count, which is the acid.
What it looks for

Every row is classified as it loads, and a row can carry more than one finding. The summary counts clean rows, rows with issues, and rows split out of mixtures. The classes are the product's own:

CleanMixtureDuplicateAtomTypeAromaticityFatalMiscCasMismatchNameMismatch
Row by row
  • Open a flagged structure in ChemiGraphy and draw the correction.
  • Edit a name or a SMILES in place; the row is re-checked afterwards.
  • Expand a mixture, tick the components you want, and split it into its own rows.
  • Look a single compound up in PubChem to fill a missing name or CAS.
  • Generate a row's tautomers, compare each with the parent, and adopt one.

Consent before any lookup. The check never contacts PubChem. Any lookup, whether a single row or the whole set, first raises a dialog naming exactly what would be sent, and waits for you to agree. Elsewhere, the Auto Fill button in Enter a compound looks a compound up only when you press it.

One Step Cure: bulk correction, with the counts up front

One dialog, four decisions, each showing how many rows it applies to. Mixtures and salts can be removed, separated into their components, or reduced to the largest part by atom count. Duplicates can be removed outright or collapsed to one row per group. Atom-type and other errors can be removed or left for manual repair.

A further section adds optional passes: strip chiral tags, neutralise negative charges, neutralise positive charge on nitrogen, and verify structures against PubChem.

Undo and redo. Fifty steps deep, and every step is named: “Undo One Step Cure”, “Undo Split into 3 components”.

Change summaries. A bulk run finishes in a summary you can filter down to the rows that need attention, ending with the balance: errors and duplicate groups, before and after.

Export. Download the clean rows or everything, as SMILES or SDF, without leaving the workspace.

Curation is built into loading. Add compounds anywhere in QSAR Flex and the same check runs. Nothing is held back: a set with issues is added with its issues visible, the toast says how many rows need looking at, and each row's panel tells you what to do about it. There is nothing to hand over afterwards: the rows you cleaned are the rows Evaluate runs on.

Routes, not just structures. N‑Nitrosation takes a multi-step synthesis as reaction SMILES or MDL RXN files and nitrosates every amine in every step, so you learn which intermediate gives which nitrosamine.

Where it runs, and what it costs
Section5

The interface is identical in both. What differs is where the models run and where the reference data they consult lives. On the web, structures are transmitted securely for the length of an evaluation and are not retained or viewed by anyone at MultiCASE. The desktop evaluates entirely on your own machine, so your structures never leave it.

Your IT team's questions are answered in the companion IT Requirements and Deployment Guide on resources.multicase.com: hostnames, paths, signing, and where structures do and do not travel.
