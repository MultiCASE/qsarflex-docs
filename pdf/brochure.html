Section 01
From a list of structures to a defensible answer

QSAR Flex is a workbench, not a single calculator. Assemble a library, clean it, choose the models to run against it, and read the results as a table you can drill into — whether you are screening one impurity or a few thousand.

STEP 01
Load
SMILES, InChI, SDF, MOL, delimited text or MDL RXN. Drop files on the page or paste structures straight in.
STEP 02
Curate
DataKurator finds mixtures, duplicates, bad atom types and aromaticity faults before they reach a model.
STEP 03
Select
Pick modules from the bundles your licence covers. Everything else stays visible but disabled.
STEP 04
Evaluate
Each compound and reaction is run against each selected module, with progress you can cancel.
STEP 05
Report
Click any outcome to open a self-contained HTML report carrying the evidence behind it.
Prediction methods
Nine ways to answer a question

A module is not always a regression. The engine carries ordinary least-squares and logistic regression, naive Bayes, random forests, Bayesian networks, expert structural alerts expressed as SMARTS, fragment descriptors, and read-across over a fingerprint reference set — including read-across localised to the environment around a specific alert. The catalog's Basis column says which kind each shipping module uses.

The method is chosen when the model is built, so a nitrosamine potency call and a boiling point arrive in the same results table.

Applicability domain
A prediction that says when to distrust it

Domain is checked explicitly, by similarity to the nearest training-set neighbours or by looking for fragments of your query that the training set never covered. An outcome outside the domain is labelled (out of domain) in the report rather than quietly returned as a number.

Where the check is fragment-based, the un-modelled part of the molecule is identified, so you can see which corner of the structure the model has never met.

Specimen — what a results row looks like
Compound Module Outcome Evidence in the report
Nitrosamine impurity CPCA Prediction Potency category · acceptable intake Decision flow-chart, activating and deactivating features highlighted on the structure
Nitrosamine impurity Surrogate Search Up to 5 surrogates TD50, species, reliability score and the regulatory acceptable intake for each surrogate
A set of NDSRIs Cross Similarity N×N similarity matrix Every pair scored against every other, so related impurities group into classes you can argue about together
Synthesis route N-Nitrosation Risk per step Nitrosamines formed at each step, scavengers and catalysts found, literature references

One file, nothing to unpack. A report is a single self-contained HTML document with the structures drawn inline as vector graphics, and print styling built in — so a browser print turns it into a paginated PDF fit for a dossier, and records the software, its version, and the run date.

What is new in 4.0

4.0 is a rebuild of everything you touch. The models, the endpoints and the numbers they return are unchanged — this release is about how quickly you can get a library in, get it clean, and get the answer out.

01
One interface, three places to run it
The web app, the Windows desktop app and the macOS desktop app now render the same interface. A 48-pixel navigation bar carries the Library / DataKurator control, the command bar, your licence status, and a light or dark theme that follows your system.
02
A command bar for every action
⌘K — or Ctrl K — opens a search over every action in the product. Commands work from any page: run one from DataKurator that belongs to the Library and you are taken there and it fires on arrival. Actions that are not available are still listed, greyed, with the reason why.
03
A library you can drop things onto
Drag a file anywhere onto the page or paste SMILES from the clipboard. Compound files and reaction files in the same drop are sorted automatically. Compounds and reactions render as cards with their structure and their results side by side, and any structure zooms into a dialog sized for it.
04
DataKurator, rebuilt around one screen
Curation and export now live together instead of behind a third step. Undo and redo cover every change and name it, One Step Cure is a single dialog with counts against every choice, and long runs report named phases and can be cancelled without losing work.
05
Your licence, in plain sight
A status chip in the navigation bar shows tests remaining, or Unlimited, or that a licence has expired. The Account page gathers Profile, Security, License and Team into one place, so a question about entitlement no longer needs an email.
06
A support portal, not an inbox
Support moves to support.multicase.com, signed in with the same MultiCASE account you use for QSAR Flex. Raise a ticket against a specific product, attach the files that show the problem, and follow the thread — with the status visible instead of guessed at.
Structures

Depictions are drawn by the engine in the current theme, so a structure is legible on paper and on a dark screen.

Empty states

Every blank screen now says what to do next, and offers the action that does it.

Partial runs

If a run returns fewer results than it was given, a banner says so — nothing is quietly presented as complete.

Cancelling

Unchanged in 4.0. Every model, every endpoint, every record count and every number a model returns. Licence types are unchanged too — subscription, on-demand subscription and pay-per-test, individual or enterprise. If you have validated a QSAR Flex result, 4.0 does not move it.

Section 03
DataKurator — get the library right first

A model can only be as good as the structure you hand it. DataKurator checks a set the moment it loads, tells you exactly what is wrong with each row, and gives you bulk and single-row tools to fix it — with undo behind every change.

What it looks for

Every row is classified as it loads, and a row can carry more than one finding. The summary counts clean rows, rows with issues, and rows split out of mixtures.

Clean Mixture Duplicate AtomType Aromaticity Fatal Misc CasMismatch NameMismatch
Row by row
Edit a name or a SMILES in place; the table asks you to re-analyse afterwards
Expand a mixture, tick the components you want, and split it into its own rows
Look a single compound up in PubChem to fill a missing name or CAS
Delete a row, or rename it, from the row menu
One Step Cure
Bulk correction, with the counts up front

One dialog, four decisions, each showing how many rows it applies to. Mixtures and salts can be removed, separated, or reduced to the largest part. Duplicates can be removed or collapsed by highest, lowest or averaged activity. Atom-type and other errors can be removed or left for manual repair.

A further section adds optional passes: strip chiral tags, neutralise negative charges, neutralise positive charge on nitrogen, and verify structures against PubChem.

Consent before any lookup

DataKurator never contacts PubChem during the initial analysis. Any lookup it makes — a single row or the whole set — first raises a dialog naming exactly what would be sent, and waits for you to agree. Elsewhere, the Auto Fill button in Add Compound is itself the instruction to look a compound up.

Undo / redo

Fifty steps deep, and every step is named — “Undo One Step Cure”, “Undo Split into 3 components”.

Change summaries

A bulk run finishes in a summary you can filter down to just the rows that still need attention.

Export

Download the clean rows or everything, as SMILES or SDF, without leaving the curation screen.

Hand-off

Load the clean compounds straight into the evaluation library in one click.

Curation is also built into loading. Add compounds anywhere in QSAR Flex and the same checks run. If something is wrong you are told how many rows and how many findings, and offered the choice of adding them anyway or sending the set straight to DataKurator to fix.

Routes, not just structures. Give N-Nitrosation a multi-step synthesis as reaction SMILES or MDL RXN files and it nitrosates every amine in every step — so you learn which intermediate gives rise to which nitrosamine, not merely whether the final API is at risk. It resolves reagents by SMILES, InChI, acronym, name or registry number, flags nitrite scavengers and catalysts, and returns similar nitrosation reactions from the literature with their references.
